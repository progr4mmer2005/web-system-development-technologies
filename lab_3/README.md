# Лабораторная работа №3

Учебное приложение из главы 3 Ruby on Rails Tutorial Майкла Хартла.
Статические страницы, ERB и автоматизированное тестирование.

## Запуск

```powershell
cd lab_3
ruby bin/setup --skip-server
ruby bin/dev
```

Приложение запускается локально на http://localhost:3000.
