# Лабораторная работа №4

Продолжение учебного приложения из лабораторной №3 по главе 4 Ruby on Rails
Tutorial Майкла Хартла. Ruby, хелперы, структуры данных и классы.

## Локальный запуск

```powershell
cd lab_4
ruby bin/setup --skip-server
ruby bin/dev
```

Rails и Guard запускаются вместе. Приложение открывается на localhost:3000.
