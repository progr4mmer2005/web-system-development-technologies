## Как работает full_title

```ruby
full_title          # => "Ruby on Rails Tutorial Sample App"
full_title("Help")  # => "Help | Ruby on Rails Tutorial Sample App"
```

`page_title = ""` — пустое название по умолчанию. `empty?` проверяет, пустая ли
строка. Если пустая, возвращаем только название приложения. Если задана,
соединяем название страницы, разделитель и название приложения.
Ruby возвращает последнее вычисленное выражение, поэтому `return` здесь не нужен.

На Help вызов `provide(:title, "Help")` запоминает название. `yield(:title)`
в общем макете получает его и передаёт хелперу. На Home вызов `provide` убрали,
поэтому `full_title` получает пустое название.

## Четыре упражнения простыми словами

**Первое:** `s.split("").shuffle.join`.
Например, `"abc"` превращается в `["a", "b", "c"]`, массив перемешивается,
затем собирается обратно в строку. Возможный результат — `"bca"`.

**Второе:** эта же цепочка внутри `class String`. Теперь можно написать
`"abc".shuffle`. `self` внутри метода — сама строка `"abc"`.

**Третье:** у каждого человека есть хеш с именем и фамилией. В хеше `params`
они лежат под ключами `:father`, `:mother`, `:child`.
`params[:father][:first]` сначала получает хеш отца, затем его имя.

**Четвёртое:** `merge` собирает новый хеш из двух. В примере ключ `"a"`
сохраняет `100`, а повторяющийся ключ `"b"` получает `300` из второго хеша.
Исходный хеш не меняется.

## Запуск и демонстрация тестов

Из папки `lab_4`:

```powershell
ruby script/exercises.rb
ruby bin/rails runner script/ruby_basics.rb
ruby bin/rails test
ruby bin/dev
```

Полный набор: 20 тестов и 49 проверок. Сервер открывается на
<http://localhost:3000>, Guard следит за изменениями. Завершение — Ctrl+C.

Чтобы показать падение и исправление:

1. В `full_title` временно заменить `base_title` на `"Wrong title"` и сохранить файл.
2. Guard запустит тесты. Проверки заголовков упадут: ожидали полное название,
   а приложение вернуло другое.
3. Вернуть `"Ruby on Rails Tutorial Sample App"` и сохранить файл.
4. Guard снова запустит тесты, и они пройдут.

Для демонстрации выборочного запуска можно сохранить изменение в
`lib/ruby_tutorial.rb`: Guard запустит только его 8 тестов. Для
`script/string_extensions.rb` запускаются только 3 теста расширения String.
Демонстрационные ошибки после защиты нужно убрать.
